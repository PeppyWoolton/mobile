# Мобильное приложение «Вязальное производство» (Android / Kivy)

Версия 1 — **чтение** из десктопной базы: **Аналитика** периода и **Загрузка машин**.
Записи нет, поэтому работа телефона не конфликтует с десктопом.

Архитектура: рядом с десктопом запускается лёгкий сервер `mobile_server.py`
(только стандартная библиотека Python, читает ту же базу через `db.py`+`ai_tools.py`).
Телефон в той же сети получает данные по HTTP и показывает их в Kivy-приложении.

```
[Десктоп + SQLite]──mobile_server.py──HTTP(LAN)──[Android, Kivy]
```

## 1. Запуск сервера (на компьютере с программой)

```bat
python mobile_server.py                 :: порт 8765, без ключа
python mobile_server.py --port 8765 --key ВАШ_СЕКРЕТ
```

Сервер печатает путь к базе и адрес. Узнайте IP компьютера в локальной сети
(`ipconfig` → IPv4, например `192.168.1.50`). Телефон должен быть в той же сети
(Wi-Fi). Откройте порт в брандмауэре Windows, если соединения не проходят.

Проверка из браузера: `http://192.168.1.50:8765/api/health` → `{"ok": true, ...}`

Эндпоинты (только GET): `/api/periods`, `/api/analytics?period=…`,
`/api/machine_load?period=…`, `/api/fact_lag?period=…`, `/api/overview?period=…`.

## 2. Сборка APK (на Linux или WSL)

Kivy собирается через **buildozer** (на Windows напрямую нельзя — используйте WSL2/Ubuntu).

```bash
pip install buildozer cython
sudo apt install -y openjdk-17-jdk
cd mobile
buildozer -v android debug      # первая сборка скачает Android SDK/NDK (долго)
# готовый файл: mobile/bin/knitting-1.0-arm64-v8a_armeabi-v7a-debug.apk
```

Перекиньте APK на телефон и установите (разрешите «установку из неизвестных
источников»).

## 2-бис. Сборка в облаке (GitHub Actions) — без компьютера

Самый простой способ получить APK: пусть его соберёт GitHub, а вы скачаете готовый
файл. В проекте уже лежит `.github/workflows/build.yml`.

1. Создайте репозиторий на github.com (можно прямо с телефона через приложение
   GitHub или веб). Залейте в него содержимое этого архива так, чтобы `buildozer.spec`
   и папка `.github` были в **корне** репозитория.
2. Откройте вкладку **Actions** → workflow **«Build Android APK»** → **Run workflow**
   (либо просто сделайте push в ветку `main`).
3. Через ~15–25 минут (первая сборка дольше — качает SDK/NDK) откройте завершённый
   запуск и скачайте артефакт **knitting-apk** (внутри `.apk`).
4. Перекиньте `.apk` на телефон и установите.

Повторные сборки быстрее за счёт кэша. Это надёжнее, чем сборка на самом телефоне.

## 3. Первый запуск на телефоне

1. Впишите адрес сервера: `http://192.168.1.50:8765` и ключ (если задавали).
2. «Подключить» → выберите период (активный подставляется сам).
3. Вкладки **Аналитика** и **Машины**. Настройки сохраняются.
